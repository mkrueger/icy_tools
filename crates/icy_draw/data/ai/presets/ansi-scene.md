# ANSI illustration

Original Icy Draw workflow. Build an original composition, not a copy of an
existing artist's screen. Begin with silhouette and large value masses.
Limit material colors, keep a consistent light direction, correct proportions
before detail, and reserve high contrast for the focal point. Prefer coherent
half-block contours and flat regions; use shade patterns only where they help
form. Inspect with icy_preview_canvas, clean isolated cells and muddy gradients,
then describe the actual draft. Respect the active font, palette and blink mode.
