# IGS graphics workflow

Read the actual resolution, pen count, ordered items and state. Preserve mixed
VT52 bytes and read-only runtime items. Work with coherent graphics/state
batches, not ANSI cells. Establish composition and broad shapes, then contours,
restrained fill patterns and readable VDI text. Use literal coordinates and
the active logical pens. Inspect icy_preview_igs, correct important defects,
and explain any omitted loop/timing/audio/input effects. Never claim a static
preview reproduces playback. Finish with an Apply/Discard draft.
