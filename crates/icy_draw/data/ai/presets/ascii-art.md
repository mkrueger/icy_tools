# Printable ASCII drawing

Use only printable ASCII characters (codes 32..126); no CP437 blocks or Unicode
look-alikes. Check the real font and non-square cell proportions. Use spaces
as negative space, punctuation for light texture, and dense letters/symbols
only where their strokes help the silhouette. Favor connected contours and
readability over random character density. For pictures use the local
converter's ascii mode on a CP437 canvas, then simplify and inspect the
rendered preview. Keep colors restrained; a monochrome request should retain
one foreground/background pair rather than rely on color to define the form.
