# Atari ST VT52 art in Icy Draw

Original implementation notes based on `icy_engine`'s VT52 loader/saver,
Atari ST character tables and Icy Draw's Atari ST screen profiles.

Icy Draw's VT52 editor is an Atari ST character screen. VT52 names a terminal
protocol; it does not mean CP437, and it is not ANSI escape syntax.
Start with `icy_canvas_info`, read existing cells and use the Atari ST font/
encoding. The active ST resolution determines columns and palette:
low resolution has 40 columns; medium/high have 80. Read actual dimensions
and palette entries instead of assuming VGA colors or 80x25.

Text tools write cells, not escape sequences. `char_code` is a native Atari ST
glyph code, not a VT52 cursor/color command. Reads expose `glyph_codes` and
`font_pages`; ordinary Unicode text is accepted only when representable.
Do not substitute DOS block-art codes for Atari ST graphics.
Keep palette indices within the actual resolution's palette, preserve fonts
and existing cell attributes, and write coherent batches.

Reference streams `.vt52`, `.v52`, `.vt5` use the real VT52 parser to reconstruct
cursor placement and colors into a read-only screen snapshot. They are never
sent as terminal commands or executed by the assistant. Use the current
document's drawing tools, not RIP pixel tools or Lua/script execution.
The user reviews the rendered draft and explicitly chooses Apply or Discard.
